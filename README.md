# Endless Sky Takeover

**Minecraft** × Endless Sky · visual · idea by the team

Bring Endless Sky into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I put Endless Sky in Minecraft: hyperspace raiders, a chicken-piloted escort shuttle, a block gas giant. Blasting pilots out of their ships never get

## Install

Install Fabric for Minecraft Java 26.3 with Fabric API, then drop the mod jar in the mods folder. Start a world: you get an Ion Blaster and credit chips. Right-click your shuttle to fly it, shoot raiders, right-click 3 chips to hire an escort.
